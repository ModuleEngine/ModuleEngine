# Диалоги и цели системных picker

[English](../editor-ui-dialogs.md) | [Русский](editor-ui-dialogs.md) | [Реестр](editor-ui-catalog.md)

Полный смысл EN/RU берётся из одного двуязычного реестра. Все картинки — предлагаемый дизайн, не снимки работающего редактора. UI на макетах английский согласно языковому контракту. Восемь категорий состояний приведены для каждого элемента; N/A объяснено. Наличие нынешнего интерфейса не означает, что предложенная вёрстка реализована.

<a id="n01"></a>

## N01 — Открытие проекта

**Существующий интерфейс; предлагаемая вёрстка.**

**Назначение:** Выбрать существующий JSON без замены документа до успешной загрузки/проверки.

**Вход:** Команда File/Tools/Assets → фоновый системный диалог с контекстным заголовком/фильтром/папкой.

**Доступ и область:** Проверки команды и файловые права ОС; нынешние нативные диалоги только Windows.

**Исходники:** [crates/editor/src/native_dialogs.rs::open_project](../../crates/editor/src/native_dialogs.rs), [crates/editor/src/editor_workflow.rs::start_dialog](../../crates/editor/src/editor_workflow.rs), [docs/editor-workflow.md](../editor-workflow.md)

### Требования

- Переход Open/Recent разрешает авторские/инструментальные черновики до принятия.

- Отсутствующий/неверный/несовместимый файл сохраняет проект/ресурсы/раскладку/привязки; Recent меняется при успехе.

- Cancel, Unicode/длинные пути и ошибка записи сохраняют проект, рабочая папка процесса не меняется.

**Действия / элементы:** `Confirm OS selection`, `Cancel`

### Состояния

| Состояние | Требуемое поведение |
| --- | --- |
| Готово / обычное | ОС владеет раскладкой/языком диалога; приложение задаёт заголовок, фильтр и текущую папку-подсказку. |
| Пусто / нет выбора | Пустая папка допустима, если цель не требует файл; правила выбора принадлежат системному диалогу. |
| Занято / подготовка | Запросом владеет один фоновый работник диалогов; редактор отзывчив, второй конфликтующий диалог не запускается. |
| Черновик / изменено | Введённый путь/имя предварительны; Cancel не возвращает выбор и не выполняет файловую операцию приложения. |
| Ошибка / отклонено | Ошибки создания/пути/прав попадают в отчёт операции; прежний проект и Recent сохраняются. |
| Ограничено / только чтение | На неподдержанной платформе честно сообщать недоступность диалогов; макет не доказывает реализацию Linux. |
| Нет данных / зависимость устарела | Исчезнувший после выбора путь перепроверяет настоящая команда; устаревшему выбору не доверяют. |
| Узкая / низкая область | Системные размещение/DPI/доступность принадлежат ОС; схема не предписывает размеры элементов ОС. |

**Клавиатура / фокус:** Фокус остаётся в активном контексте; Escape отменяет только его незавершённый жест или popup.

**Данные / жизненный цикл:** Сохранить точные авторские данные, стабильные ID и личный вид; использовать существующие проверенные историю/сохранение.

**Проверка реализации:**

- Открыть указанным путём; проверить обычное и все применимые состояния без изменения другой области.

- Проверить права, узкую раскладку, фокус, сохранность при Cancel/ошибке и настоящий результат команды.

**Макеты:** [Основной вид](../media/editor-ui-catalog/n01.svg) · [Лист состояний](../media/editor-ui-catalog/n01-states.svg).
