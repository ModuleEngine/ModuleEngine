## V01 — GPU-граф рендера

**Существующий интерфейс; предлагаемая вёрстка.**

**Назначение:** Соединять настоящие проходы и типизированные ресурсы выбранного рендера.

**Вход:** Открыть подграф рендера в Module Blueprint/Overview; это не новый EditorType.

**Доступ и область:** Full/исходники, установленные GPU-описания и совместимость PassManifest по format/semantic/extent/samples.

**Исходники:** [crates/render-vulkan/src/graph.rs::default_graph](../../crates/render-vulkan/src/graph.rs), [crates/editor/src/app.rs::is_gpu_graph_scope](../../crates/editor/src/app.rs), [docs/gpu-hlsl.md](../gpu-hlsl.md)

### Требования

- Пример Forward: Scene → Geometry → SSAO → Tone map → FXAA → Color encode → Frame; Deferred добавляет G-buffer/lighting и настоящие связи.

- Пины показывают смысл и тип/формат/размер/samples; raster/compute Custom HLSL сохраняет объявленные ресурсы.

- Удаление/возврат AO/AA согласует настройки, проверяет связи и сохраняет рабочий рендер при отказе.

**Действия / элементы:** `Add GPU pass`, `Inspect resource`, `Open HLSL`, `Delete selection`, `Review preset`

### Состояния

| Состояние | Требуемое поведение |
| --- | --- |
| Готово / обычное | Видны выбранные данные и настоящая доступность команд. |
| Пусто / нет выбора | Нет рабочего Frame output: показать отсутствие маршрута и совместимые ноды, не строить pipeline молча. |
| Занято / подготовка | Показать настоящую операцию и последнюю рабочую ревизию; блокировать конфликтующие правки, не навигацию. |
| Черновик / изменено | Отметить локальные правки отдельно от сохранённого/применённого; записывать через существующую проверенную транзакцию. |
| Ошибка / отклонено | Несовместимость называет оба порта/ограничения; неверная связь/неявное преобразование не принимаются. |
| Ограничено / только чтение | Показать конкретное ограничение Full/Team/исходников/Play; вкладка раскладки не выдаёт права. |
| Нет данных / зависимость устарела | Удалённый проход — Absent, не Disabled; его разрешения/варианты не остаются действующими. |
| Узкая / низкая область | Сложить второстепенное вертикально или убрать в явное меню; сохранить область, основное действие, ошибку и навигацию без уменьшения текста. |

**Клавиатура / фокус:** Фокус остаётся в активном контексте; Escape отменяет только его незавершённый жест или popup.

**Данные / жизненный цикл:** Сохранить точные авторские данные, стабильные ID и личный вид; использовать существующие проверенные историю/сохранение.

**Проверка реализации:**

- Открыть указанным путём; проверить обычное и все применимые состояния без изменения другой области.

- Проверить права, узкую раскладку, фокус, сохранность при Cancel/ошибке и настоящий результат команды.

## V02 — Маршрут настройки рендера

**Предложенный интерфейс; не реализован.**

**Назначение:** Объяснить архитектуру рендера и разрешённые настройки игры одним маршрутом.

**Вход:** Предложенный Overview → Rendering; изменения вызывают те же команды графа/настроек.

**Доступ и область:** Архитектура/разрешения требуют Full; Project выбирает только разрешённые значения/варианты.

**Действия / элементы:** `Open rendering graph`, `Edit exposure`, `Choose permitted AA`, `Review preset`

**Вход:** History / Merge → Prepare merge → выбранный конфликт.

**Доступ и область:** Те же проверки исходников/ресурсов, что при восстановлении; файл с конфликтами не рабочий принятый проект.

- Apply после разрешений/проверки; Save result with conflicts подписан отдельно, авторский проект сохраняется.

## V06 — Инспектор визуальной ноды Rust

**Существующий интерфейс; предлагаемая вёрстка.**

**Назначение:** Объяснять/менять поддержанные scalar/command-ноды с сохранением текстовых фрагментов.

**Вход:** Выбрать ноду графа Rust; исходник/слот видим.

**Доступ и область:** Настоящая поддержанная нода парсера и правила исходника, не произвольный AST всего языка.

**Исходники:** [crates/editor/src/app.rs::code_inspector](../../crates/editor/src/app.rs), [crates/editor/src/panels.rs::command_inspector](../../crates/editor/src/panels.rs)

### Требования

- Показать операцию и редактируемые типизированные значения только при поддержке.

- Непрозрачный Rust открывается текстом; визуальная правка меняет тот же исходник через кандидата.

- Экземпляры Custom не разделяют изменяемое состояние из-за общего скомпилированного кода.

**Действия / элементы:** `Edit supported value`, `Open fragment as text`

### Поля и привязки

Тип widget описывает отображение, не новый тип сериализации. Значения примеров не являются правками пользовательского проекта; readonly не рисуется текстовым полем.

| Элемент UI | Вид | Пример | Контракт / привязка |
| --- | --- | --- | --- |
| Source / slot | `readonly` | game-controller | Выбранный исходник/слот не меняется подписью ноды. |

## V13 — JSON игрового расписания

**Существующий интерфейс; предлагаемая вёрстка.**

**Назначение:** Редактировать JSON-черновик ресурсов/этапов как вид того же Gameplay Systems.

**Вход:** Gameplay Systems → расширенный execution JSON; возврат к тому же графовому черновику.

**Доступ и область:** Замороженное расписание Team, Full/исходники и Stop Play сохраняются; JSON не обход.

**Исходники:** [crates/editor/src/game_ui.rs::systems_ui](../../crates/editor/src/game_ui.rs), [docs/module-execution.md](../module-execution.md)

### Требования

- Область — GameProject.execution, не весь GraphDocument и не Rust/HLSL.

- Показать синтаксис/ошибки привязок/зависимостей; Apply проверяет общий черновик, Discard возвращает расписание.

- Текстовый Undo локален; Save не принимает незавершённый черновик неявно.

**Действия / элементы:** `Apply schedule`, `Discard draft`, `Return to graph`

### Состояния

| Состояние | Требуемое поведение |
| --- | --- |
| Готово / обычное | Видны выбранные данные и настоящая доступность команд. |
| Пусто / нет выбора | Объяснить отсутствие выбора или пустой список; предлагать только поддержанное создание или переход. |
| Занято / подготовка | Показать настоящую операцию и последнюю рабочую ревизию; блокировать конфликтующие правки, не навигацию. |
| Черновик / изменено | Отметить локальные правки отдельно от сохранённого/применённого; записывать через существующую проверенную транзакцию. |
| Ошибка / отклонено | Неверный ID/тип ресурса или after сохраняет executor и точный редактируемый текст. |
| Ограничено / только чтение | Показать конкретное ограничение Full/Team/исходников/Play; вкладка раскладки не выдаёт права. |
| Нет данных / зависимость устарела | Сохранить доступность стабильных ID и отсутствующих ссылок; не подменять и не включать зависимость молча. |
| Узкая / низкая область | Сложить второстепенное вертикально или убрать в явное меню; сохранить область, основное действие, ошибку и навигацию без уменьшения текста. |

**Клавиатура / фокус:** Фокус остаётся в активном контексте; Escape отменяет только его незавершённый жест или popup.

**Данные / жизненный цикл:** Сохранить точные авторские данные, стабильные ID и личный вид; использовать существующие проверенные историю/сохранение.

- Проверить права, узкую раскладку, фокус, сохранность при Cancel/ошибке и настоящий результат команды.
