[English](../editor-ui-windows.md) | [Русский](editor-ui-windows.md) | [Реестр](editor-ui-catalog.md)

Полный смысл EN/RU берётся из одного двуязычного реестра. Все картинки — предлагаемый дизайн, не снимки работающего редактора. UI на макетах английский согласно языковому контракту. Восемь категорий состояний приведены для каждого элемента; N/A объяснено. Наличие нынешнего интерфейса не означает, что предложенная вёрстка реализована.

## P01 — Обзор Engine

**Существующий интерфейс; предлагаемая вёрстка.**

**Назначение:** Понять технический состав этого проекта и перейти к настоящим настройкам.

**Вход:** Раскладка Engine; Windows → Engine Overview; открытие использует подходящую область.

**Доступ и область:** Нынешний инструмент требует прав Engine/исходников; сохранённая недоступная область показывает причину, не открывает доступ Team.

**Исходники:** [crates/editor/src/engine_overview.rs::engine_overview_panel](../../crates/editor/src/engine_overview.rs), [crates/editor/src/dock.rs::EditorType](../../crates/editor/src/dock.rs)

### Требования

- Разделить Technical Engine, переиспользуемый Gameplay, Project и Unknown.

- Независимо показать проект/основание конфигурации/права и доказательства installed, offered, participating.

- Использовать настоящие переходы; просмотр не запускает фабрики и компиляцию.

- Использовать уточнённый макет иерархии: интервалы по роли строки, маркер выбора, сдержанные границы и не более одного основного действия в контексте. Факты только для чтения визуально отличаются от редактируемых полей.

- Развести группы состава, выбор подсистемы и подробности по визуальным уровням. Поставить настоящий переход к render graph рядом с выбранным рендером; сохранить installed/offered/participating и ограничение сведений о готовности runtime.

**Действия / элементы:** `Open render graph`, `Show renderer node`, `Source details`, `Refresh evidence`

### Состояния

| Состояние | Требуемое поведение |
| --- | --- |
| Готово / обычное | Выбранные группа и подсистема имеют постоянные маркеры; в подробностях рендера одно основное действие Open render graph. Показать Installed, Offered, Participating тремя фактами, не значком Ready. |
| Пусто / нет выбора | Нет совпавших возможностей. Очистить поиск; это не доказательство пустого движка. |
| Занято / подготовка | Использовать доступные снимки и обозначить ожидание данных; чтение не запускает фабрику, сервис или компилятор. |
| Черновик / изменено | Не применяется: окно не владеет авторским черновиком; несохранённость проекта показывается в каркасе. |
| Ошибка / отклонено | Объяснить сбой получения/чтения данных и сохранить прежнюю читаемую запись с происхождением. |
| Ограничено / только чтение | Скрыть или заблокировать неподдержанный переход по настоящим правам; сохранённая область ничего не разблокирует. |
| Нет данных / зависимость устарела | Данные о возможности недоступны: Unknown и источник/ошибка, не отметка неактивности. |
| Узкая / низкая область | В dock-области 480 точек открыть выбранную подсистему с Back to composition. Сохранить права/контекст, поддержанные действия и доказательства; выбор и поиск сохраняются при возврате. Это вариант области, не целое окно ОС. |

**Клавиатура / фокус:** Фокус остаётся в активном контексте; Escape отменяет только его незавершённый жест или popup.

**Данные / жизненный цикл:** Сохранить точные авторские данные, стабильные ID и личный вид; использовать существующие проверенные историю/сохранение.

**Проверка реализации:**

- Открыть указанным путём; проверить обычное и все применимые состояния без изменения другой области.

- Проверить права, узкую раскладку, фокус, сохранность при Cancel/ошибке и настоящий результат команды.

- Осмотреть основной макет и узкую область 480 точек: определить контекст, выбор, основное действие и черновик/наследование без опоры только на цвет. Статические предложения не доказывают работоспособность нативного ввода.

**Визуальная иерархия:** [правила и геометрия](editor-ui-hierarchy.md).

## P02 — Module Blueprint / корневой граф

**Существующий интерфейс; предлагаемая вёрстка.**

**Назначение:** Просматривать и менять корневой процесс модулей, не путая его с GPU-проходами или игровым расписанием.

**Вход:** Windows → Module Blueprint; Overview открывает настоящий выбранный корневой граф.

**Доступ и область:** Full с полными совпадающими исходниками; действуют проверки исходников и кандидатов.

**Исходники:** [crates/editor/src/panes.rs::module_graph_area](../../crates/editor/src/panes.rs), [crates/editor/src/app.rs::graph_panel](../../crates/editor/src/app.rs)

### Требования

- Показать настоящий путь области и состояние документа/Apply.

- Целевое управление: СКМ/ПКМ, колесо под курсором, действия ПКМ фона/ноды и смешанные Delete/Undo.

- Один источник данных: inspector, JSON и граф; открытие подграфа не создаёт универсальный scheduler.

- Не рисовать постоянный ряд Add/Open/Frame/Delete. ПКМ фона открывает добавление, двойной щелчок ЛКМ — существующий разрешённый подграф, F кадрирует текущий граф, Delete удаляет выделение. Контекстные меню остаются обнаруживаемыми эквивалентами тех же команд.

**Действия / элементы:** `Add node`, `Open subgraph`, `Frame graph`, `Delete selection`

### Состояния

| Состояние | Требуемое поведение |
| --- | --- |
| Готово / обычное | Холст начинается сразу под заголовком области, без повторных кнопок Add/Open/Frame/Delete. Контекстные действия и жесты относятся к тому же текущему графу и существующим проверяемым командам. |
| Пусто / нет выбора | Показать No nodes с контекстной подсказкой Right-click to add, доступной областью и настоящей совместимой палитрой. Не создавать стандартные ноды ради заполнения холста. |
| Занято / подготовка | Показать настоящую операцию и последнюю рабочую ревизию; блокировать конфликтующие правки, не навигацию. |
| Черновик / изменено | Отметить локальные правки отдельно от сохранённого/применённого; записывать через существующую проверенную транзакцию. |
| Ошибка / отклонено | Неверная связь/нода: показать концы и точное несовпадение; сохранить рабочий исполняемый граф. |
| Ограничено / только чтение | Показать конкретное ограничение Full/Team/исходников/Play; вкладка раскладки не выдаёт права. |
| Нет данных / зависимость устарела | Сохранить доступность стабильных ID и отсутствующих ссылок; не подменять и не включать зависимость молча. |
| Узкая / низкая область | Сложить второстепенное вертикально или убрать в явное меню; сохранить область, основное действие, ошибку и навигацию без уменьшения текста. |

**Клавиатура / фокус:** При фокусе холста графа: F кадрирует текущий граф, Delete удаляет смешанное выделение через проверку/один Undo. Двойной щелчок разворачиваемой ноды вне пинов/встроенных полей открывает подграф; текст, popup и модальные окна получают ввод первыми. Щелчок ПКМ добавляет/открывает действия; СКМ/ПКМ drag двигает вид; колесо масштабирует. Escape отменяет текущий жест. Клавиша меню/Shift+F10 открывает контекстное меню цели сфокусированного графа как предлагаемый клавиатурный эквивалент.

**Данные / жизненный цикл:** Сохранить точные авторские данные, стабильные ID и личный вид; использовать существующие проверенные историю/сохранение.

**Проверка реализации:**

- Открыть указанным путём; проверить обычное и все применимые состояния без изменения другой области.

- Проверить права, узкую раскладку, фокус, сохранность при Cancel/ошибке и настоящий результат команды.

- Проверить отсутствие постоянного ряда и оставленной под него пустой полосы; создание ПКМ, двойной щелчок подходящей ноды, F/Delete сфокусированного холста и меню сохраняют область, приоритет фокуса и Undo. Это предлагаемый контракт ввода, не доказательство нативной реализации.

## P04 — Разрешения Project в Engine

**Существующий интерфейс; предлагаемая вёрстка.**

**Назначение:** Определить, какие именно параметры и готовые варианты может менять игровой проект.

**Вход:** Переход настройки из Overview или Windows → Engine Exposure.

**Доступ и область:** Только Full и полные совпадающие исходники; Project не добавляет архитектуру и не расширяет собственные разрешения.

**Исходники:** [crates/editor/src/properties.rs::engine_settings_panel](../../crates/editor/src/properties.rs), [docs/settings.md](../settings.md)

### Требования

- Сгруппировать параметры, наборы вариантов/значения по умолчанию и определения участвующих возможностей.

- Выдавать только существующие подходящие параметры/реализации; снятие разрешения согласованно убирает осиротевшие значения Project.

- Различать разрешения PropertySchema и владельца ComponentSchema; показать исходные pins и границы.

**Действия / элементы:** `Expose parameter`, `Stop exposing`, `Configure variant set`

### Поля и привязки

Тип widget описывает отображение, не новый тип сериализации. Значения примеров не являются правками пользовательского проекта; readonly не рисуется текстовым полем.

| Элемент UI | Вид | Пример | Контракт / привязка |
| --- | --- | --- | --- |
| Exposed parameter ID | `readonly` | tone-map.exposure | Стабильный ID разрешения/цели, не свободное значение. |
| Default / minimum / maximum | `vector3` | 1.0 / 0.0 / 8.0 | Числовая схема/default Engine; здесь подписи Default / Min / Max, не пространственные оси. |
| Allowed AA variants | `readonly` | Off / FXAA | В разрешённый набор входят только подходящие настоящие реализации. |
| Default AA | `enum` | FXAA | Default engine.exposure.variants из разрешённых вариантов. |
| Feature definitions | `readonly` | Participating source owners only | engine.enabled_modules и исходный владелец остаются явными. |

## P05 — Настройки Project

**Существующий интерфейс; предлагаемая вёрстка.**

**Назначение:** Настраивать разрешённые значения и правила игры без замены архитектуры движка.

**Вход:** Tools → Project Settings или Windows → Project Settings.

**Доступ и область:** Только разрешённые Engine элементы и схемы участвующих владельцев; скрипты подчиняются тем же правилам.

**Исходники:** [crates/editor/src/properties.rs::project_settings_panel](../../crates/editor/src/properties.rs), [docs/settings.md](../settings.md)

### Требования

- Разделить авторское значение, действующий default и активный вариант.

- Правила выбирают только существующие варианты; первое совпавшее правило группы приоритетно.

- Отсутствующие модули не имеют действующих настроек; выбор AA не меняет набор разрешённых реализаций.

**Действия / элементы:** `Edit value`, `Choose allowed variant`, `Add rule`, `Remove rule`

### Поля и привязки

Тип widget описывает отображение, не новый тип сериализации. Значения примеров не являются правками пользовательского проекта; readonly не рисуется текстовым полем.

| Элемент UI | Вид | Пример | Контракт / привязка |
| --- | --- | --- | --- |
| Exposure | `number` | 1.0 | project.parameters для разрешённого ID; конечные значения в границах схемы. |
| Anti-aliasing | `enum` | FXAA | project.variants выбирает только разрешённые Off / FXAA этого примера. |
| Rule 1 | `readonly` | Time >= 1.0 → AA = FXAA | Условие/вариант упорядоченного правила; менять типизированными элементами, не свободным выражением. |
| Architecture | `readonly` | Defined by Engine | Project не расширяет набор вариантов и не заменяет рендер. |

| Пусто / нет выбора | Нет подходящих разрешённых настроек: их задаёт Engine; не показывать посторонние сетевые/боевые поля. |
| Занято / подготовка | Показать настоящую операцию и последнюю рабочую ревизию; блокировать конфликтующие правки, не навигацию. |

**Существующий интерфейс; предлагаемая вёрстка.**

### Требования

- Сгруппировать Transform, parent/prefab/ресурсы и компоненты; не дублировать общий заголовок.

Нынешнее пересоздание кеша после Apply/смены выбора не подтверждает сохранность других черновиков; защита таких переходов — будущее требование реализации.

### Поля и привязки

Тип widget описывает отображение, не новый тип сериализации. Значения примеров не являются правками пользовательского проекта; readonly не рисуется текстовым полем.

| Garden | `enum` | First steps | Выбрать ID существующей сцены G1; переключение недоступно при изменённом черновике этого инструмента. |
| Width | `number` | 8 | Ширина сетки черновика, целое 3–32; правки локальны до проверенного Apply level. |

| Cell size | `number` | 1.0 | Размер клетки черновика 0.1–4.0, скорость drag 0.05; успешный Apply даёт один Undo. |

## S02 — Дополнительное нативное окно

**Реализованный интерфейс; свидетельства приёмки ограничены [проверкой хостов](release-042-area-hosts-verification.md).**

**Назначение:** Вынести область в другое окно ОС с общим документом/историей.

**Вход:** Area → Move to new window или отрыв за свободный заголовок. Перенос к краю основного/плавающего листа выполняет docking; команды Return нет.

**Доступ и область:** Тот же проект/права; настоящее OS-окно содержит дерево разбиений, это не встроенная плавающая панель egui.

**Исходники:** [docs/editor-clarity-plan.md](../editor-clarity-plan.md), [docs/editor-ui-spec.md](../editor-ui-spec.md), [crates/editor/src/panes.rs::PaneSnapshot](../../crates/editor/src/panes.rs)

### Требования

- Переносить один лист, не дублировать его; сохранять ID и камеру/навигацию. Основной и плавающий хосты используют общее меню Area и отрисовку дерева; разбиение/выбор типа остаются в хосте.

- Area Close удаляет только адресованный лист. Системный × закрывает все текущие листы данного хоста; другие хосты/проект остаются открыты. ID хоста сохраняется после закрытия исходного первого листа. Явный drag docking сохраняет ID/виды листов. Закрытые листы отсутствуют после сохранения/повторного открытия. Объяснение Close последней основной области — подсказка при наведении на недоступную команду, а не постоянный абзац меню.

- Правки/Undo общие; перерисовка/ресурсы/фокус по нативному окну, включая восстановление монитора/DPI.

**Действия / элементы:** `Split horizontally`, `Split vertically`, `Close area · keep neighboring area`, `Move to new window`; системный × закрывает хост.
