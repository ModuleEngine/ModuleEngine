## Статус, единицы и источник значений

**База дизайна от 14 ноября 2026 года; внедрение в нативный UI выполняется в этапе 2A.**
См. [настоящее внедрение и доказательства](editor-ui-rollout.md); одна спецификация
не означает приёмки всех элементов управления.
[Дизайн](editor-ui-design.md) объясняет причины и объём.
[editor-ui-tokens.json](../editor-ui-tokens.json) — машиночитаемый источник
предлагаемых размеров/цветов; этот документ определяет их назначение и поведение.
При изменениях обновлять обе языковые версии и токены вместе. JSON — данные
документации, а не загрузчик или новая зависимость. Это предложения ModuleEngine,
а не размеры, скопированные из редакторов-референсов.

Все длины/кегли — **логические точки egui**, а не физические пиксели,
типографские пункты или CSS-единицы. При текущем системном масштабе и увеличении
пользователя `physical_pixels = logical_points × pixels_per_point`; нельзя
умножать геометрию на DPI дважды. Масштаб графа меняет только граф, а не текст
приложения, вкладки раскладок и пороги мыши. Тонкие линии выравнивать по текущей
сетке физических пикселей. Использовать согласованное семейство UI без засечек
с проверенным английским/кириллицей; сохранить текущий шрифт, пока не проверены
покрытие и лицензия замены.

[Каталог интерфейсов](editor-ui-catalog.md) применяет правила к каждой нынешней
цели окна/диалога, вложенному виду и запрошенному интерфейсу с отдельными макетами
и листами состояний. Системные picker нарисованы схематично, без предписания
геометрии ОС. Генератор и локальный атлас — инструменты документации, не код редактора.

Минимум **4,5:1 для всего доступного текста** и **3:1 для значимых иконок,
контуров фокуса и необходимых границ** относительно каждой реальной соседней
поверхности. Это внутренние ориентиры по источникам W3C из дизайна, а не
сертификация доступности нативного приложения. Проверять реальное смешивание,
а не только пары hex; элементы overlays имеют непрозрачную поверхность.
Исключения для недоступного/декоративного не должны скрывать важный статус.
Цвета пинов — подсказки типов вместе с именем, направлением и подробностями
несоответствия. Цвет пина не определяет принадлежность к игровому слою.

## Прототипы визуальной иерархии

[Уточнение P01/P08/P09](editor-ui-hierarchy.md) применяет плотность по роли
к трём выбранным интерфейсам. Ограниченная ими группа токенов `hierarchy`
задаёт строки навигации 40, двухстрочных подсистем 56, фактов 28, полей 36,
интервалы групп/разделов 24/32 и предел подписи/содержимого Inspector 112/720.
Высота полей остаётся 28. Выбранный предмет использует 20 semibold, разделы 16,
поля 14, метаданные 12. Значимый выбор обозначается фоном и маркером/галочкой,
отдельно от фокуса клавиатуры.

Только основное контекстное действие использует сплошной accent с текстом
on_accent. Связанные факты группируются отступами вместо повторных обводок;
границы полей остаются видимыми. Узкий SVG шириной 480 точек — вариант
dock-области с прежним размером текста, не приёмка всего окна/DPI. Apply
Inspector относится к компоненту; операции Assets сохраняют существующие
защиты. Это предлагаемые макеты документации, не глобальное переоформление
нативного редактора или всех остальных листов каталога.

## Каркас редактора, раскладки и окна

Верхняя строка: File/Edit/Tools/Windows слева, рядом именованные вкладки раскладок
и **+**. Панель проекта: имя/доступ к пути, несохранённость, реальные права,
Play/Pause и Stop, Save и текущая операция. Управление Play держать вместе на
постоянном месте; сохранение — отдельная группа. Строка состояния: краткое
состояние операции и раскрываемая диагностика. Не повторять версию/слоганы демо
в основной рабочей области. Продукт/версия могут быть в About или диагностике.

Нативное [уплотнение оболочки](release-042-ui-density-verification.md)
заменяет прежние 8-точечные отступы Project в реализованном редакторе. Общие
локальные метрики оболочки при масштабе UI 100%: поля 1 точка и промежутки
2 точки. Кнопки Project сохраняют высоту 32 и равные поля по 1 сверху/снизу;
заголовок области имеет высоту 30 с переключателем/кнопкой Area высотой 28,
внутреннее поле области — 1 точку. Разделитель занимает только 2 видимые точки,
сохраняя 8-точечную зону захвата над содержимым; переключатель и Area владеют
своим вводом. Интервалы меню/раскладок и свёрнутые строки операций/статуса
уплотнены. Раскрытая диагностика сохраняет обычные строки, прогресс, ошибки
и действия. Эти локальные переопределения не меняют шрифты, строки форм/меню
и отступы Assets/Inspector. Таблица предложений выше по-прежнему описывает
общую проектную основу.

<a id="command-ownership"></a>

### Владение командами и повторное управление

Для одной сессии Game Play общая верхняя панель владеет единственным постоянно
видимым пультом: Play меняется на Pause/Resume по состоянию, далее Stop и Restart,
где поддержан. Save — отдельная команда проекта. Не размещать второй ряд
Play/Stop/Restart внутри Game. Локальная панель владеет действиями вида, например
Focus game, и видимой индикацией фокуса ввода/состояния сессии. Это целевая
компоновка макета, не рефакторинг нативного редактора.

Project File сохраняет локальные Apply file и Discard draft; Save Project
остаётся в общей панели/меню File. Apply Rust/HLSL, Apply schedule, Apply level,
Apply компонента, checkpoints и разрешение merge имеют другие цели/транзакции;
их нельзя удалять по совпадению названий с общим Save.

Аудит управления во всём каталоге различает эти случаи:

| Интерфейс / маршрут | Решение |
| --- | --- |
| P10 Game | Убрать повторный локальный ряд жизненного цикла; в примере Playing показать Pause/Stop/Restart один раз в общей панели. |
| P14 Project File | Убрать повторный локальный Save; сохранить обе команды черновика. |
| P17 legacy 3D preview | Убрать Start/Pause: нативные viewport_panel и общий PlayPause используют Editor.playing. Сохранить подписанные Reset preview (legacy runtime/время) и Open configuration. |
| C01–C04 образцы компонентов | Убрать общий пульт жизненного цикла/Save. C03 подписывает образцы иконок; C04 — инструментов/состояний и убирает лишний Save. Образцы не являются исполняемыми элементами редактора. |
| Меню File/Tools и горячие клавиши | Сохранить обнаруживаемые альтернативные входы в одну команду; это не второй постоянно видимый пульт. |
| D01 защита сохранения/перехода | Сохранить Save and continue: он разрешает ожидающий переход, не является второй обычной панелью Save. Модальное окно владеет вводом; фоновый каркас не становится вторым активным пультом. |
| Остальные маршруты каталога | Других постоянно видимых пультов одной цели в действиях и командах рендера макетов не найдено. Разные области/транзакции остаются доступны. |

Нативный общий флаг PlayPause также относится к legacy preview; этот дизайн
не вводит отдельное время preview. Его Reset очищает этот legacy runtime и время,
а Game Restart относится к Game host. Аудит включает все 72 записи и три узких
варианта; проверяются назначение/цель
команды и повторные иконки. Это выводы по документации в границах нынешних
исходников, не новая приёмка нативного UI. Для новых элементов до добавления
второго видимого ряда нужно определить владельца/цель команд.

При нехватке места сохранять идентичность текущего проекта. Сначала убирать
вкладки раскладок в меню переполнения, сокращать показанный путь с доступом к
полному/копированию, второстепенные команды переносить в подписанное меню.
Не уменьшать шрифт. При доступной клиентской ширине меньше 480 логических
точек или высоте меньше 240 основной и плавающий хосты показывают одну активную
область и переключатель; остальные остаются доступны. Обычный плавающий хост
760×510 показывает настоящее дерево разбиений. Это адаптивный маршрут,
а не обязательный минимум размера окна. Минимальные размеры ограничивать
реальной рабочей областью монитора с учётом оформления ОС. Экран 1080p при 200%
не вмещает окно шириной 1100 логических точек.

Сохранить существующие ID раскладок и личное хранение; не сбрасывать их молча.
Сохранение раскладки отделено от авторского Undo/истории и несохранённости.
В меню границы: **Split Horizontally**, **Split Vertically**, команда объединения/
закрытия с именем или предпросмотром сохраняемой области. То же меню доступно
из заголовка для обнаружения и клавиатуры. Закрытие последней основной области
оставляет рабочую замену, а не пустую невосстановимую раскладку.

Отдельным окнам ОС нужны стабильные ID viewport/областей, общий документ и
история команд, отдельное состояние вида. Внедрённый заголовок отдельного окна
содержит общий с основной областью выбор типа, Area и свободное место переноса.
Меню Area — векторное вертикальное троеточие справа с подсказкой/именем
доступности Area. Сохраняются заголовок/название ОС, системный × и нативная рамка изменения размера,
в том числе при переносе за клиентский заголовок. Внутри нет второго × и File/Edit.
У каждого плавающего хоста своё дерево разбиений, общее с основным хостом меню
Area и операции. Area Close удаляет один лист; системный × закрывает все текущие
листы этого хоста. ID хоста сохраняется после удаления его исходного листа.
Разбиение и выбор редактора сохраняют принадлежность хосту; явный drag docking
переносит лист. Команды Return в меню нет. Последний основной лист защищён;
причина доступна при наведении на недоступный Close. Окна вне экрана возвращаются на доступный
монитор без сброса содержимого. При переносе между мониторами с разным DPI
физические размеры пересчитываются один раз. Встроенная плавающая панель egui
не называется отдельным нативным окном ОС.

Основной и плавающие хосты Editor используют исходный ICO ModuleEngine без изменения
всех семи кадров (16/24/32/48/64/128/256).
При создании окна передаются общие данные значка; на Windows малый и большой
значки дополнительно назначаются точному своему HWND при создании или повторной
привязке. Активное окно не служит идентификатором плавающего хоста. Ресурсы EXE и
оформление Player не меняются. [Проверки значка и визуальные границы](release-042-window-icon-verification.md).

## Иконки, подсказки и состояния

Использовать общий каталог векторов и один источник команд для панели/меню/
горячих клавиш. Это рекомендация по реализации: документ не добавляет новую
абстракцию команд в приложение. Избегать emoji, зависящих от шрифта Unicode-
замен и разных семейств иконок по панелям. Маленькие знаки должны быть простыми
и различимыми при 100/150/200%. Сторонним иконкам нужна лицензия на исходное
и бинарное распространение. Каталог предлагает общую собственную векторную
геометрию; стороннее семейство иконок не устанавливается.

| Элемент | Пиктограмма | Содержимое подсказки/доступности |
| --- | --- | --- |
| Play / Pause / Resume | треугольник / две полосы / треугольник | Настоящее действие и состояние. Play запускает копию, Pause сохраняет её. Только поддержанные состояния. |
| Stop | квадрат | Остановить Play и вернуться к авторской Scene. Недоступно без активной сессии. |
| Save | узнаваемый символ диска/сохранения | `Save Project · Ctrl+S`; различать отсутствие изменений, авторские правки/черновики и ошибку сохранения. |
| Move / Rotate / Scale | четыре стрелки / круговая стрелка / ручки масштаба | `Move · G`, `Rotate · R`, `Scale · S`; выбранный инструмент явно отмечен. |
| Кадрирование выбранного | углы рамки | `Frame Selection · F`; отсутствие выбора объясняет недоступность. |
| Snap | магнит | Переключатель с отметкой, текущий шаг и подписанное меню настроек. Числовую настройку шага не прятать за необъяснённой иконкой. |
| World/Local | оси координат с состоянием | Значение `World` или `Local` остаётся видно рядом/внутри компактного переключателя: одной иконки недостаточно. |

Предложение не назначает новых горячих клавиш Play/Stop. Показывать только
реальную привязку. Подписи отражают действующий keymap; не импортировать W/E/R
другого редактора. Текстовые меню сохраняют обнаруживаемый эквивалент иконок.

Состояния: обычное, наведение, нажатие, фокус клавиатуры, выбрано/включено,
недоступно и занято/ошибка там, где это применимо. Выбор — фон и акцентная
отметка; фокус — собственный контур 2. Несохранённость отличается от ошибки
Apply. Иконка занятости не скрывает Stop, если остановка реально поддержана.
Каждая интерактивная иконка предоставляет слою доступности семантическое имя
и применимые checked/disabled-состояния. Статический SVG-макет не доказывает
работу этого API.

На сплошной акцентной заливке использовать внутренний контур фокуса `on_accent`
или отделять внешний акцентный контур промежутком цвета canvas. Акцентный контур
вплотную к такой же заливке не выполняет правило контраста значимого состояния.

Структура подсказки: **действие и назначенная клавиша**, короткое предложение
об эффекте, текущее значение или причина недоступности, когда нужно. Пример:
`Play` / `Run a copy of the authored scene.` / `Unavailable: preparing game logic.`
Наведение и клавиатурный фокус дают равнозначную справку, включая недоступные
элементы через доступную для фокуса/справки обёртку при необходимости. Подсказка
остаётся при наведении/фокусе, допускает перемещение указателя на неё и закрывается
по Escape. Критичная ошибка и последствия разрушительного действия не должны
обнаруживаться только наведением.

## Инструменты поверх Scene

Координаты ниже отсчитываются от **прямоугольника изображения** после заголовка
области высотой 32. Они не резервируют ещё одну строку инструментов на всю ширину.

| Группа | Геометрия и размещение |
| --- | --- |
| Панель трансформаций | Отступ слева/сверху 8; ширина 44 = отступ 4 + зона нажатия 36 + отступ 4. Три кнопки с промежутком 4: общая высота 124. Знаки 20 по центру. |
| Ориентация трансформации | Одна переключаемая кнопка: глобус = World axes, куб = Local axes. Подсказка называет текущий режим и следующее действие; Local подсвечен. Ширина группы 44 = отступ 4 + зона 36 + отступ 4. Полей привязки здесь нет. |
| Скорость камеры | Рядом с ориентацией — группа шириной 120 с одним числовым полем Speed размером 112×36. По умолчанию 8 единиц мира/с, диапазон 0,1–1000. Доступна во время Play, сохраняется для личной области, а не в игровом проекте. |
| Привязка | Отдельная группа шириной 84: магнит включает привязку; ползунки открывают только шаги Move/Rotate/Scale. Между группами 8, зоны нажатия 36 с промежутком 4. Изменение шага не переключает оси. |
| Действия вида | Отдельная группа Frame selected шириной 44. Четыре группы сверху/справа занимают 316 точек с отступом 8 сверху/справа и промежутками 8. Высота всех групп 44, элементов — 36, верхние границы и центры совпадают. Общего меню осей и привязки нет. |

При ширине 400 группа шириной 316 не перекрывает панель трансформаций. |

Поверхности групп непрозрачные `raised`; небольшие промежутки, тонкие разделители,
без большого пустого заголовка. Меню/подсказки ограничиваются текущим viewport/
рабочей областью. Если высоты не хватает для боковой панели, она сворачивается
в выбор инструмента с названиями. Активный инструмент остаётся обнаруживаемым.
Фиксированные места — первая база; свободное перетаскивание и сохранённые
overlay-пресеты пока только возможное развитие.

Overlays рисуются после изображения и перед временными меню/справкой. Их зоны
поглощают ввод до выбора объектов/манипуляторов; прозрачное место вне
прямоугольников не блокирует навигацию. Жест сохраняет владельца до отпускания/
Cancel, включая пересечение overlay. Законченная трансформация создаёт один Undo,
Escape возвращает исходную. Скрытые/свёрнутые инструменты не удерживают невидимый
захват указателя. У Game остаётся игровое управление; это авторские инструменты
Scene, а не игровой HUD.

Доработанный Scene поддерживает полёт на удержании ПКМ + WASD, Q вниз/E вверх
по мировой оси Y и обзор вокруг
положения камеры, независимо от игровой камеры, авторской сцены и Undo. ПКМ
должна быть нажата именно на этом изображении сцены; панели, текст, меню и
активное перетаскивание объекта сохраняют приоритет ввода. Принадлежность колеса
определяется порядком событий, даже если нажатие/отпускание ПКМ и прокрутка пришли
в одном кадре. Во время полёта S двигает назад вместо выбора Scale. ПКМ + колесо меняет скорость (×1,25 за
строку/40 точек) без зума и его остаточного движения; обычное колесо по-прежнему
меняет расстояние. При сочетании осей вектор нормализуется на выбранную скорость.
Отпускание ПКМ, Escape, потеря фокуса,
открытие меню, скрытие области или смена документа прекращают полёт. СКМ для
вращения вокруг цели, Shift+СКМ для сдвига, колесо для расстояния и F в активном
Scene сохраняются. Скорость, ограничение времени и границы работы указателя
описаны в [управлении Scene](scene-assets.md).

## Граф и каталог модулей

Показывать понятный путь области, например `Engine / Rendering / Main`, и
состояние проверки/применения. Путь обозначает реально открытый граф; пример
не добавляет новую сериализованную иерархию. Сохранить границы исполнения
root/GPU/gameplay. Добавление ноды использует настоящий реестр и права области,
а не глобальный каталог несовместимых технических и игровых элементов.

В root Module Blueprint нет постоянного ряда Add/Open/Frame/Delete; холст
занимает освобождённую высоту. ПКМ фона открывает Add Node; двойной щелчок ЛКМ
подходящей разворачиваемой ноды открывает существующий подграф; F кадрирует
текущий граф; Delete удаляет выделение. Меню ноды показывают те же действия и
подписи клавиш для обнаружения/клавиатуры. В пустом графе допустима контекстная
подсказка Right-click to add. Это целевое управление макетов; изменение
документации не реализует его в нативном редакторе.

База ноды: ширина 220, минимум 180/максимум 360; заголовок 28; отступы тела 12;
строки пинов 24; зона пина 16; связь толщиной 2 с допуском попадания 6.
Названия переносятся или сокращаются с полным текстом в справке; смысл пина
остаётся доступным. Направление/подписи дополняют цвет. При сильном отдалении
упрощать детали ноды вместо нечитаемых существенных надписей; выбор/вписывание/
подробности остаются доступны. Предлагаемый масштаб — 0,25–2,5 вокруг указателя.
Сохранить загруженное состояние вида; принятие пределов само по себе не
переписывает авторский файл.

Каталог/popup: ширина 280–360 с ограничением по месту; поиск сверху, строки 28
с категорией и понятными именами. Одна прокрутка занимает оставшуюся высоту;
подробности/справка не зависят от фиксированного предела списка 360/420.
Если графовых областей несколько, показывать явное понятное назначение.
Действия ноды соответствуют настоящей поддержке/правам. Экспорт исходников/
workspace относится к File/Tools, а не к основному списку добавления нод.

Справка пина показывает понятный смысл, технический тип, направление,
ограничения и существенные значения. Пример: `Depth texture · input` и
настоящие требования формата/размера, без придуманных ограничений для примера.
Неверная связь объясняет конкретное несоответствие и сохраняет прежние
соединения. Необязательная справка “Connection types” заменяет постоянный
необъяснённый подвал `PIN CONTRACTS`. Не ослаблять валидатор ради видимой
совместимости упрощённых подписей.

### Владелец ввода и приоритет

| Контекст/жест | Поведение |
| --- | --- |
| Модальное окно, popup, текстовое поле или overlay | Сначала собственные события. Текстовые Delete/Undo и контекстное меню текста остаются текстовыми. |
| ПКМ на разделителе областей | Управление областями, без меню нод под ним. Разделитель вне содержимого графа. |
| Перетаскивание СКМ в графе | Переместить вид этого графа без авторской правки. |
| ПКМ в графе | Отложить решение о меню. После перемещения на 6 логических точек двигать вид; при отпускании без перетаскивания открыть действия фона/ноды у исходной цели. Отпускание после движения не открывает меню. |
| Колесо без Ctrl над холстом | Масштаб под указателем; списки/popup прокручиваются сами, если владеют указателем. Масштаб графа не меняет каркас UI. |
| Alt+ЛКМ по связи | Один раз удалить эту связь, поглотить щелчок до действий ноды/фона. |
| ЛКМ по ноде / перетаскивание ноды | Выбор / перемещение нод. Проверки попадания пинов и встроенных элементов приоритетнее перетаскивания тела. |
| Двойной щелчок ЛКМ разворачиваемой ноды | Открыть существующий разрешённый подграф; drag, пин или встроенное поле текста/значения не запускают переход. |
| F в сфокусированном холсте графа | Кадрировать текущий граф без его изменения; текст, popup и модальные окна сохраняют свои клавиши. |
| Клавиша меню / Shift+F10 в сфокусированном графе | Предлагаемый клавиатурный эквивалент: действия сфокусированной цели-ноды, иначе Add фона. Текстовые поля сохраняют собственное контекстное меню. |
| Перетаскивание ЛКМ по фону | Рамка выделения, не движение вида. Предлагаемые модификаторы: Shift добавляет, Ctrl переключает; перед реализацией сверить с текущим keymap. |
| ЛКМ по связи / смешанный выбор | Выбрать связь или добавить к нодам/связям; показать отличимый контур выбора. |
| Delete в сфокусированном графе | Удалить выбор с прилегающими связями, очистить связанные настройки, проверить и записать одну атомарную транзакцию Undo. Другие области графа не затрагиваются. |
| Escape / потеря фокуса | Отменить незавершённый жест, закрыть временный UI и отпустить захват; не применять частичное удаление молча. |

Пороги/допуски задаются в экранных логических точках и не уменьшаются при
отдалении графа. Перекрывающиеся кандидаты разрешаются определённо по ближайшей
видимой связи/порту; невидимая за экраном связь не перехватывает щелчок.
Смысловые правки графа подчиняются существующим правилам валидации/последней
рабочей версии; движение/масштаб/выбор не запускают компиляцию или пересборку.
Большим спискам нужны отсечение/виртуализация и ограниченная работа со строками/
раскладкой; сначала измерять, затем добавлять кеши или абстракции.

## Assets и панели подробностей

Начальная ширина дерева 200, рабочий минимум 160; отступ уровня 16, строка 28,
отдельные знаки раскрытия и папки. Идентичность выбранного элемента сохраняется
между Tiles/List. Плитка 96×96 с иконкой/preview 48 и промежутком 8; имя до двух
строк с доступом к полному. Строки List 28 с типовыми иконками и понятными
колонками. Высота адреса/крошек 32. Подробности начинаются с 240 и сворачиваются.

При ширине Assets меньше 640 сначала сворачивать подробности с явной командой
Details. Если дерево с содержимым всё ещё не помещаются — одна колонка с
переходом Folders/назад. Поиск/фильтр, текущая папка и выбор остаются видимыми.
Переполнение крошек сохраняет корень/текущую папку, середина уходит в меню.
Показ и копирование адреса используют одно каноническое текущее расположение.
Относительный/абсолютный формат и жест переключения остаются открытыми решениями
дизайна; выделяемое поле не означает ручного перехода по введённому адресу.

Папки отличаются от файлов формой при любом масштабе и в монохромном виде.
Выбор, копирование пути и смена вида не вызывают rename/move/delete. Файловые
операции сохраняют [контракт транзакций Assets](asset-workspace-api.md),
ссылки и корзину проекта. При недоступном ресурсе сохранять его идентичность/
ссылку с полезной диагностикой, а не показывать пустую плитку.

## Проверки

Каждая реализованная часть получает доказательства до/после с привязкой к HEAD,
дайджесту исходников, артефакту, target/features и настоящему сценарию.
Независимое ревью следует [контракту проекта](review.md). Нынешняя поставка
документации/навыков проверяет ссылки, языковое соответствие, токены/контраст,
отрисовку макета и поведение навыков; она не заявляет новой нативной приёмки
или производительности.

| Проверка | Что наблюдать в будущей реализации |
| --- | --- |
| Геометрия/читаемость | Физические рабочие области 1280×720, 1600×900, 1920×1080 при 100/150/200% и перенос между разными DPI; ограничивать реальной рабочей областью ОС. Проверить длинные подписи, узкие/низкие отдельные области. |
| Иконки/справка | Узнать Play/Pause/Stop/Save и трансформации; фокус клавиатуры, checked/disabled/busy, настоящие клавиши, читаемые подсказки и Escape. Семантические имена/состояния доступности проверить в настоящем backend. |
| Раскладки/окна | Личная раскладка загружается без изменений; вкладки/+ и Cancel меню границы; закрытие/возврат/перезапуск отдельного окна ОС, общий Undo и отсутствие второго состояния проекта. |
| Ввод графа | Все конфликты таблицы ввода, отпускание ПКМ после движения, масштаб под указателем, смешанные Delete/Undo и недоступное действие; текст и другие области графов сохраняются. |
| Данные/права | Save/reopen, Cancel, ошибки Apply/экспорта/файловой транзакции, неизвестные данные и фикстуры Team/отсутствующих исходников/модулей; без неявной активации. |
| Assets/Scene | Узнаваемые папки/копирование пути, стабильные ссылки после разрешённых операций, инструменты/жесты; без выбора сквозь overlays, один Undo и откат Escape. |
| Обратная связь | Различимые dirty/saved/applied/failed; подпись последнего рабочего кадра; нет вымышленного процента или неработающей Cancel. |
| Производительность | Сравнить одинаковые перетаскивание/масштаб графа, idle, Scene и Playing до/после на одном ПК с теми же настройками артефакта. Записать распределения callback/кадров и нагрузку; чистое движение вида не компилирует код. |

При затрагивании рендера/игры существующие бюджеты сохраняются; статический
макет или быстрый callback не подтверждает FPS Player. Непроверенные нативные
условия ОС/доступности/вывода кадра нужно перечислить, а не выводить их из
headless-проверки или маленькой фикстуры.


При изменении нативного окна фактический размер сохраняется для следующего
сеанса. Чтение размера или положения из ОС не создаёт новую команду размера или
положения. Явные перемещения раскладки, создание/пересоздание хоста и смена
мониторов/масштаба сохраняют маршрут размещения.
[Доказательства и границы исправления](release-042-resize-jitter-verification.md).
