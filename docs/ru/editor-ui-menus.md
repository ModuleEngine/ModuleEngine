# Меню и контекстные команды

[English](../editor-ui-menus.md) | [Русский](editor-ui-menus.md) | [Реестр](editor-ui-catalog.md)

Полный смысл EN/RU берётся из одного двуязычного реестра. Все картинки — предлагаемый дизайн, не снимки работающего редактора. UI на макетах английский согласно языковому контракту. Восемь категорий состояний приведены для каждого элемента; N/A объяснено. Наличие нынешнего интерфейса не означает, что предложенная вёрстка реализована.

## M01 — File и подменю

**Существующий интерфейс; предлагаемая вёрстка.**

**Назначение:** Предоставить команды контекста без изменения документа от открытия меню.

**Вход:** Верхнее File и его подменю

**Доступ и область:** Действуют исходники/Team, выбранная область и проверки команд.

**Исходники:** [crates/editor/src/editor_workflow.rs::draw_workflow_toolbar](../../crates/editor/src/editor_workflow.rs), [docs/editor-ui-spec.md](../editor-ui-spec.md)

### Требования

- Учесть настоящие New/Recent/Export и условный выбор состава; единый движок не стирает нынешние пункты.

- Вызывать существующие защищённые команды; открытие не создаёт файлы и не меняет Engine/проект.

- Recent обозначает файл/полный путь и сохраняет проект при ошибке открытия.

**Действия / элементы:** `New Project >`, `Templates >`, `Open Project…`, `Recent Projects >`, `Save Project`, `Save As…`, `Import Asset…`, `Export >`, `Exit`

### Состояния

| Состояние | Требуемое поведение |
| --- | --- |
| Готово / обычное | Видны понятные имена команд, отметки, настоящие клавиши и доступность. |
| Пусто / нет выбора | Показывать отсутствие совпадений только для поиска/динамического списка; статическое меню сохраняет полезные недоступные пункты. |
| Занято / подготовка | Блокировать конфликтующие команды с причиной; открытие/закрытие меню не запускает операцию. |
| Черновик / изменено | Не применяется: меню не владеет черновиком данных; нужные черновики разрешает вызываемая команда. |
| Ошибка / отклонено | Ошибка команды показана её инструментом/результатом операции; закрытие меню не теряет черновик. |
| Ограничено / только чтение | Доступность следует проверке команды; справка недоступного пункта объясняет права или контекст. |
| Нет данных / зависимость устарела | Удалить устаревшую динамическую цель или оставить её недоступной с причиной; не вызывать повторно использованный ID. |
| Узкая / низкая область | Ограничить рабочей областью ОС, прокручивать длинные списки, сохранить фокус клавиатуры и доступ к подменю. |

**Клавиатура / фокус:** Стрелки двигают фокус, Enter вызывает доступную команду, Escape закрывает внутренний popup. У текстовых полей своё меню.

**Данные / жизненный цикл:** Сохранить точные авторские данные, стабильные ID и личный вид; использовать существующие проверенные историю/сохранение.

**Проверка реализации:**

- Открыть указанным путём; проверить обычное и все применимые состояния без изменения другой области.

- Проверить права, узкую раскладку, фокус, сохранность при Cancel/ошибке и настоящий результат команды.

**Макеты:** [Основной вид](../media/editor-ui-catalog/m01.svg) · [Лист состояний](../media/editor-ui-catalog/m01-states.svg).

**Вход:** Щелчок ПКМ фона, либо клавиша меню/Shift+F10 при фокусе холста без цели-ноды (предлагаемый клавиатурный путь). В root Blueprint нет постоянной кнопки + Node.

**Доступ и область:** Действуют исходники/Team, выбранная область и проверки команд.

**Исходники:** [crates/editor/src/canvas.rs::draw](../../crates/editor/src/canvas.rs), [docs/editor-ui-spec.md](../editor-ui-spec.md)

### Требования

- Отпускание после движения не открывает поиск; добавление использует исходную область/позицию.

- Root/GPU различаются; Gameplay Systems использует палитру систем, Rust — только поддержанные операции.

- Enter подтверждает доступное, Escape закрывает; без декоративных недоступных нод/произвольного AST Rust.

**Действия / элементы:** `Search nodes`, `Scope`, `Compatible categories`, `Create selected`

### Состояния

| Состояние | Требуемое поведение |
| --- | --- |
| Готово / обычное | Видны понятные имена команд, отметки, настоящие клавиши и доступность. |
| Пусто / нет выбора | Показывать отсутствие совпадений только для поиска/динамического списка; статическое меню сохраняет полезные недоступные пункты. |
| Занято / подготовка | Блокировать конфликтующие команды с причиной; открытие/закрытие меню не запускает операцию. |
| Черновик / изменено | Не применяется: меню не владеет черновиком данных; нужные черновики разрешает вызываемая команда. |
| Ошибка / отклонено | Ошибка команды показана её инструментом/результатом операции; закрытие меню не теряет черновик. |
| Ограничено / только чтение | Доступность следует проверке команды; справка недоступного пункта объясняет права или контекст. |
| Нет данных / зависимость устарела | Удалить устаревшую динамическую цель или оставить её недоступной с причиной; не вызывать повторно использованный ID. |
| Узкая / низкая область | Ограничить рабочей областью ОС, прокручивать длинные списки, сохранить фокус клавиатуры и доступ к подменю. |

**Клавиатура / фокус:** Стрелки двигают фокус, Enter вызывает доступную команду, Escape закрывает внутренний popup. У текстовых полей своё меню.

**Данные / жизненный цикл:** Сохранить точные авторские данные, стабильные ID и личный вид; использовать существующие проверенные историю/сохранение.

**Проверка реализации:**

- Открыть указанным путём; проверить обычное и все применимые состояния без изменения другой области.

- Проверить права, узкую раскладку, фокус, сохранность при Cancel/ошибке и настоящий результат команды.
