# module-engine-physics-rapier

[English](README.md) | [Русский](README.ru.md) | [Документация](../../docs/ru/README.md)

Опциональный шаг физики на 60 Гц, устанавливаемый из исходников. Он
регистрирует систему `physics.rapier` и схемы тела, коллайдера и сустава.
Core владеет ECS и переносимым API запросов. Rapier предоставляет
решатель отдельной сцены и отладочную геометрию для возможности Editor
`debug-draw`. См. [контракт физики и команды проверки](../../docs/ru/physics-rapier.md).
