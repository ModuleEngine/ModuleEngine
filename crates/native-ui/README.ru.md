# Оконный интерфейс Vulkan

[English](README.md)

Editor и Player используют этот крейт для вывода окон egui через Vulkan. Корневое окно и отделённые панели используют одно логическое устройство. Рендерер графа, подключённый к оконной цели, передаёт готовое выходное изображение в `FrameBridge`. Зарегистрированная текстура удерживает изображение, пока оно нужно интерфейсу.

Копия egui-ash-renderer 0.13.0 под лицензией MIT в `../vendor/egui-ash-renderer` различает текстуры графа и egui. Граф выдаёт RGBA8 с прямой альфой. Для согласованного с egui смешивания фрагментный шейдер умножает цвет каждого отсчёта на альфу перед интерполяцией. После изменения шейдера пересоберите версионируемый бинарный файл из каталога `src/shaders` этой библиотеки.

```sh
glslangValidator -V shader.frag -o shader.frag.spv
```

Запустите проверку из корня репозитория в графическом сеансе. Она рисует три уровня прозрачности, освобождает рендерер и сравнивает пиксели из цепочки показа с ожидаемым результатом смешивания.

```sh
cargo run --locked -p module-engine-player --features ui,vulkan --example gpu_presentation_check -- work/window-pixels.json --window
```

Проверка также удерживает четыре аренды при смене размера и сравнивает три текселя после двух частичных обновлений текстуры egui. В реестре ей соответствует `native-window-graph-pixels`. Для сверки SPIR-V вершинного шейдера используйте `glslangValidator -V shader.vert -o shader.vert.spv`.
